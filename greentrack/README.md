# Green Track 綠野追蹤

永續行動碳足跡紀錄 APP — 高保真互動原型。

依據《第四章 AI 輔助 UI 設計創作實踐‧第一節 傳統使用者介面設計創作實踐》所述之
50 個介面畫面（圖 4-1 至圖 4-50）實作，配色取樣自品牌標誌，並以品牌吉祥物「小綠」
貫穿引導、註冊回饋、AI 建議與成就等情感化設計節點。

## 啟動方式

```bash
npm install
npm run dev
# 開啟 http://localhost:3000/greentrack.html
```

`npm run build` 會同時輸出既有的 EduPrompt（`index.html`）與本原型（`greentrack.html`）。

## 色彩系統

色票直接自 `assets/logo.webp` 取樣，定義於 `tailwind.config.js` 與 `theme.ts`：

| 角色 | 色票 | 取樣來源 | 用途 |
| --- | --- | --- | --- |
| 主色 | `#8B82AD` purple-500 | 水滴主體 | 按鈕、主標題、主要資訊 |
| 主色深階 | `#5B5382` purple-700 | 水滴陰影 | 按壓狀態、深色卡片 |
| 輔色一 | `#BCE4F0` aqua-200 | 水滴內襯 | 飲食模組、漸層收尾 |
| 輔色一深階 | `#3FA8C6` aqua-500 | 水滴內襯 | 飲食模組主色 |
| 輔色二 | `#9DCC9F` leaf-300 | 標誌葉片 | 環保商城、正向回饋 |
| 輔色二深階 | `#5A9C60` leaf-500 | 標誌葉片 | 成功狀態 |
| 點綴色 | `#C49BC1` mauve-400 | 孔雀羽毛 | 選取態、目標線 |
| 功能色 | `#F2C572` amber-300 | 品牌延伸 | 集點碳積分模組 |

論文所述之模組色彩分區（主功能藍紫、集點橙黃、飲食天藍、商城綠、帳戶紫）完整保留，
但所有色相皆收斂至上述品牌色票，避免各模組各自為政。

## 互動細節

論文中描述的關鍵互動皆為可操作實作，而非靜態示意：

- **體重刻度尺**（圖 4-16）：刻度隨數值平移，下方標籤同步更新，並即時計算 BMI 與分類回饋。
- **身高垂直刻度尺**（圖 4-17）：以垂直方向對應真實量身高情境，指示線隨數值升降。
- **出生年份滾輪**（圖 4-14）：中央選中值以藕紫粗體顯示，上下相鄰年份淡化。
- **交通替換比較**（圖 4-34）：切換交通工具即時重算碳排與減碳量，並以長條對照各方式。
- **減碳成果**（圖 4-36）：今日／每週／每月／年度四種週期切換，折線圖與統計同步更新。
- **碳排儀表板**（圖 4-37/4-38）：點擊儀表板展開詳細說明，重現論文之展開狀態。
